FAKE NEWS DETECTION | AAI-2602

1. Установите Python 3.10+ и зависимости: python -m pip install -r requirements.txt
2. Запустите меню: python main.py
3. Для проверки работы выберите пункт 2 (искусственные тестовые данные).
4. Для исследования скачайте Fake.csv и True.csv с Kaggle в data/raw/.
5. Выполните: python main.py run --raw data/raw

Полная инструкция: README.md. Шпаргалка: docs/defense_notes.md.
Приложенные отчёт, презентация и demo_run - демонстрация работы кода, не результаты на Kaggle.
После реального запуска новые Report.pdf и Presentation.pdf появятся в новой папке runs/.
MiniLM: установить requirements-embeddings.txt и добавить --include-minilm.
Весь проект протестирован для четырёх офлайн-моделей. MiniLM в этой среде не выполнялся.
GitHub: https://github.com/Marticat/fake-news-detection-aai2602 (приватный).
