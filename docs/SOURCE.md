# Research data provenance

Requested data card: https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

Executed files were downloaded on 2026-11-14 from the public ISOT mirror:
https://github.com/emilurosev/isot-fake-news-dataset/tree/aa8ca45d9da5a308479c52d121c42f36a1f97e69

The mirror README attributes the corpus to a Kaggle ISOT republication. We do not claim byte-for-byte verification against the requested Kaggle archive. The executed CSV hashes and counts are recorded in data_manifest.json. Actual combined input: 44,898 rows, 116,372,816 bytes.

The selected corpus is below the recommended 500,000 rows or 200 MB. Duplication would not add independent evidence. An instructor-approved exception remains necessary if this recommendation is enforced for the selected topic.

Download True.csv and Fake.csv using GitHub's Download raw file button and place them in data/raw. Original ISOT documentation: https://onlineacademiccommunity.uvic.ca/isot/wp-content/uploads/sites/7295/2023/02/ISOT_Fake_News_Dataset_ReadMe.pdf
